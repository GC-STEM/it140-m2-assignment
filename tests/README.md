# Construct Phase

**SDLC progress:** [0 Start Here](../README.md) → [1 Analyze](../analysis/README.md) → [2 Design](../design/README.md) → **3 Construct** → [4 Test](../tests/README.md) → [5 Submit](https://learn.snhu.edu/)

## Purpose

During the Construct phase, you turn the provided design into a working Python program.

You will complete the `name_age.py` starter file in small steps. Use the supplied pseudocode as your main coding guide and refer back to the SRS and SDD when you need to confirm what the program should do.

## Deliverable

**This phase produces a deliverable.**

You will complete [`name_age.py`](./name_age.py) during this phase. After completing the Test phase, you will submit this file in **D2L Brightspace** for grading as part of the Module Two Assignment.

The Module Two Assignment also includes a separate IDE Features Reflection deliverable. You will complete that separately.

## What You Will Use

Use the following provided materials to complete this phase:

* [`name_age.py`](./name_age.py) — the Python starter file that you will complete and later submit for grading.
* [Pseudocode](../design/name_age.pseudo) — your primary step-by-step guide for writing the program.
* [Software Design Document (SDD)](../design/name_age_sdd.md) — provides additional information about the planned solution.
* [Software Requirements Specification (SRS)](../analysis/name_age_srs.md) — defines what the completed program must do.
* [Software Development Worksheet (SDW)](../analysis/name_age_sdw.md) — contains your working notes from the earlier phases.

Relevant topics you have already studied in zyBooks include basic input and output, variables and assignments, identifiers, arithmetic expressions, type conversion, and string formatting.

> **Starter-file note:** `name_age.py` contains some code structure that you have not studied yet. This structure has been provided for you. Leave the provided imports, `main()` function structure, main guard, and other starter code in place unless the activity instructions specifically tell you to change them. Complete the marked sections using the programming concepts you have learned so far.

## What You Will Do

1. Open [`name_age.py`](./name_age.py) and read the entire starter file before changing anything.

2. Review the instructions and `TODO` comments. Use the supplied [pseudocode](../design/name_age.pseudo) to connect each coding task to a step in the design.

3. Complete the module docstring at the top of the file in **your own words**, following the instructions in the starter file. Do not use AI to generate this required original documentation.

4. Add your Python code one small step at a time where the starter file directs you to do so.

5. Keep your solution within the Python concepts introduced through Module Two. You do not need branching, loops, classes, or other later-course techniques for this assignment.

6. Run the program after each meaningful change. Correct simple errors before adding the next part.

7. Use clear variable names, appropriate whitespace, and comments where they help explain the code.

8. When your program is complete, remove remaining instructional placeholder text and `TODO` comments as directed by the starter file.

> **IDE Features Reflection reminder:** As you write code, notice features such as **Python syntax highlighting** and **code completion** in VS Code. Consider whether they make code easier to read, help you recognize Python elements, or reduce typing errors. This experience may be useful later when you complete the separate [IDE Features Reflection](../ide_features.md).

## Check Your Work

Before continuing, make sure:

* [ ] I used the provided pseudocode as a guide for my code.
* [ ] I completed each required section of `name_age.py`.
* [ ] I left the provided starter structure in place unless instructed otherwise.
* [ ] My code uses concepts appropriate for Modules One and Two.
* [ ] I used clear names, readable whitespace, and appropriate comments.
* [ ] I completed the module docstring in my own words.
* [ ] I removed instructional placeholders and `TODO` comments that the starter file tells me to delete.
* [ ] I saved `name_age.py` and can run it without a Python error.

## Help and Support

If you have difficulty completing this phase:

* Start with the [pseudocode](../design/name_age.pseudo) and work on one step at a time. Refer to the [SRS](../analysis/name_age_srs.md) if you are unsure what the program must do.
* Review the relevant topics from zyBooks Chapters 1 and 2, especially basic input/output, variables, expressions, type conversion, and string formatting.
* See the [Module Two Assignment Wiki](https://github.com/GC-STEM/it140-m2-assignment/wiki) for supplemental programming and course-IDE guidance.
* Use [GitHub Discussions](https://github.com/GC-STEM/it140-m2-assignment/discussions) for questions about using the repository or [GitHub Issues](https://github.com/GC-STEM/it140-m2-assignment/issues) to report a technical problem with its files or tools.
* Contact your instructor through D2L Brightspace for questions about assignment requirements, grading, or feedback.
